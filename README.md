# AEROWARD — Jackets / Fashion & Apparel

Premium responsive fashion website concept inspired by the *visual language* of the referenced Birdman template: fullscreen imagery, Ken Burns motion, content transitions, image rails, animated editorial panels, dark/light contrast, and smooth content changes. The design/content is original and not a copy of the referenced template.

## Pages
- `index.html` — Home, 6 sections including the full-screen hero
- `collections.html` — Collections, 3 sections
- `services.html` — Services, 4 sections
- `about.html` — About, 3 sections
- `contact.html` — Contact, dummy details, form, social icons, OpenStreetMap live map
- `login.html` — centered login, social buttons, forgot password
- `signup.html` — centered signup with Terms checkbox
- `dashboard.html` — centered dashboard workspace with no navbar/footer and logout

## Notes
- All contact information is intentionally dummy/fictitious.
- Image URLs are external Pexels sources and include error-free fallback behavior through CSS backgrounds/structured image areas.
- Connect the contact form/login/signup to a real backend before production.
